# 나의 AI 플레이리스트 취향 찾기

토브리치와 AI 유튜브 플레이리스트 0기 1회차 실습용 웹앱입니다.

## 주요 기능
- 로그인/회원가입 없이 바로 시작
- 10개 질문으로 음악 취향 탐색
- 14개 장르 점수 계산 및 상위 3개 추천
- 7080 Old Pop / 7080 Folk·Ballad / Trot / Trot Ballad / CCM·Worship 포함
- 플레이리스트 아이디어와 YouTube 검색어 제안
- 결과 카드 인쇄/저장
- 모바일 대응

## 사용 목적
장르를 잘 모르는 초보자와 시니어 수강생이 질문에 답하면서 자신에게 맞는 AI 유튜브 플레이리스트 방향을 찾도록 돕는 수업용 도구입니다.

## 안내
7080·CCM 등의 결과는 특정 기존 곡을 복제하는 의미가 아니라, 해당 시대감·분위기·주제를 참고한 새로운 창작 음악 방향을 뜻합니다.
